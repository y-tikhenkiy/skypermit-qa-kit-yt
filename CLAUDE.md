# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Мета проєкту

QA-кит для застосунку **skypermit** (Next.js + Supabase, лежить у `../skypermit`). Цей репозиторій використовується переважно для **генерації тест-кейсів і тест-планів** на основі документації skypermit, а **не** для написання автоматизованих тестів.

Основні вхідні дані — `../skypermit/docs/`:

- `01-data-model.md` — модель даних
- `02-state-machine.md` — стани та переходи
- `03-api-contract.md` — API-контракт
- `04-frontend-spec.md` — специфікація фронтенду
- `05-open-questions.md` — відкриті питання
- `06-business-rules.md` — бізнес-правила
- `07-clarifications.md` — уточнення
- `08-uml-diagrams.md` — UML-діаграми

Тест-кейси мають спиратися на ці документи; у кейсах посилайся на джерело (файл і розділ). Якщо документи суперечать один одному або покривають не все (див. `05-open-questions.md`, `07-clarifications.md`), познач це явно, а не вигадуй поведінку.

## Структура директорій (плановано)

- `test-cases/` — згенеровані тест-кейси та тест-плани (Markdown).
- `.claude/skills/` — скіли для повторюваних сценаріїв генерації (наприклад, тест-кейси за state machine, за API-контрактом, тест-план).

Наразі в репозиторії є лише `README.md`; ці директорії ще не створені. Створюй їх за потреби відповідно до цієї схеми.

## Заборони щодо `../skypermit`

`../skypermit` — **строго read-only**:

- Не редагуй, не створюй, не видаляй і не перейменовуй файли в `../skypermit`.
- Не запускай там команд, що змінюють стан: `npm install`, збірку, міграції Supabase, `git` з записом (commit, checkout, reset тощо), форматери/лінтери з `--fix`.
- Лише читання: `docs/` — основне джерело; код (`app/`, `lib/`, `supabase/`, `tests/`) читай тільки для уточнення деталей, не змінюючи.
- Усі результати роботи зберігай виключно в цьому репозиторії.

## Команди

Збірки, лінтингу чи тестів у цьому репозиторії немає.
